# Ikona možganov

`brain-noto-512.png` je lokalna kopija ikone Noto Emoji 17.0 za možgane s prosojnim ozadjem. Generator iz nje izdela `brain-art.png` z vidnim črnim obrisom, tesno obrezano `brain-symbol.png` za ikone velikosti emojija ter logotip, ikono zavihka in ikone za namestitev aplikacije z rožnatim ozadjem (`#F472B6`). Faviconi PNG, SVG in ICO imajo enako kvadratno ozadje in približno 1,5-pikseljski črn rob pri velikosti 32 × 32; korenska datoteka `favicon.ico` podpira Live Server in klasično samodejno iskanje brskalnikov. Zato prikaz ni odvisen od emoji-pisave ali operacijskega sistema.

Ikone ponovno ustvari z ukazom `node scripts/build-icons.js`. Datoteka `OFL-NotoEmoji.txt` vsebuje licenco izvorne umetnine.
